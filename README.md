# PDF Reader

Простая читалка PDF для Android без рекламы и лишних разрешений: список недавних файлов,
просмотр с панелью, оглавлением, переходом к странице и режимом чтения, в котором на экране
остаётся только документ.

## Возможности

- Открытие PDF через системный выбор файлов (SAF), из проводника, по кнопке «Поделиться»
  и из мессенджеров. Документы, к которым другие приложения дают доступ только на один раз,
  копируются в приватное хранилище, чтобы оставаться в недавних (до 256 МБ).
- Недавние файлы: до 15 записей с датой открытия и страницей, на которой остановились;
  дубликаты одного файла с разными ссылками схлопываются. Долгое нажатие: показать папку,
  убрать из списка, удалить файл с устройства.
- Просмотр: вертикальное или горизонтальное листание, слитная лента или по одной странице,
  ночной режим (инверсия), не гасить экран, не переворачивать экран.
- Оглавление документа, переход к странице по номеру, ссылки внутри документа,
  документы под паролем.
- Тап по странице прячет панель, ползунок и системные бары; повторный тап возвращает.
- Поворот экрана не перечитывает документ и не сбрасывает масштаб и прокрутку.
- Открытый из другого приложения документ живёт в своей задаче, а не внутри чужой.

Отрисовка — библиотека [android-pdf-viewer](https://github.com/mhiew/android-pdf-viewer) (pdfium).
Разрешений на доступ к памяти приложение не запрашивает. Список недавних не попадает в резервные копии.

## Структура

```
app/src/main/java/com/example/pdfreader/
├── MainActivity.kt                    единственный экран: недавние файлы и просмотрщик
├── RecentFiles.kt                     модель и хранилище списка недавних
├── RecentFilesAdapter.kt              список недавних
├── RecentFileActionsDialogFragment.kt действия с записью: папка, убрать, удалить
├── ImportedDocuments.kt               копии одноразовых документов в приватном хранилище
├── ReaderSettings.kt                  настройки просмотра (SharedPreferences)
├── SettingsDialogFragment.kt          диалог режима просмотра
├── OutlineDialogFragment.kt           оглавление
├── JumpToPageDialogFragment.kt        переход к странице
├── PasswordDialogFragment.kt          пароль к документу
├── ConfirmDialogFragment.kt           подтверждения
├── LockableScrollHandle.kt            ползунок, который можно спрятать намертво
└── ReportingLinkHandler.kt            ссылки в документе + сигнал «тап был по ссылке»
```

Юнит-тесты (Robolectric): `app/src/test/` — недавние файлы, настройки, импорт документов.

## Сборка

Нужны JDK 17+ и Android SDK (платформа 37). Минимальная версия Android 8.0 (API 26).

```bash
./gradlew testDebugUnitTest   # юнит-тесты
./gradlew assembleDebug       # APK в app/build/outputs/apk/debug/
```
